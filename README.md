# Sistema de Monitoramento de Reservatório 

Este é um projeto simples em Python desenvolvido para simular o monitoramento dos níveis de água de um reservatório. Ele exibe mensagens de alerta no terminal com cores diferentes para cada nível de risco.

## Tecnologias Utilizadas
- **Python 3**
- **Colorama** (Biblioteca para manipulação de cores no terminal)

## Níveis de Alerta
- Nível 1: Muito baixo (crítico) - Vermelho
- Nível 2: Baixo - Amarelo
- Nível 3: Médio - Verde
- Nível 4: Alto - Ciano
- Nível 5: Muito alto (alerta) - Azul

## Como executar
1. Clone este repositório.
2. Instale a biblioteca colorama: `pip install colorama`
3. Execute o arquivo principal: `python monitoramento.py`
